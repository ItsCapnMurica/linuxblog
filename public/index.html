What is a Virtual Machine?

There are two ways to boot an operating system, or OS. Those two ways are directly on your PC, or in a VM But what is a VM? A VM, or virtual machine, is a way to boot an operating system without doing it on your actual PC. A VM can be used to test out operating systems, open suspicious files, or anything else you could imagine. What does a VM do? A VM spoofs real hardware as much as it can while not actually being real hardware, however there are still ways to tell. Even if the OS can tell it is being run in a VM, most don’t care. Most OSes you would ever try to run in a VM function no differently than if it was running on real hardware, so no worries about it not booting because of that. What Is Linux? Understanding the Kernel

A lot of people say “Linux” and mean a whole operating system — but technically, Linux is just the kernel. Everything else (the desktop, the terminal, the package manager) comes from somewhere else entirely. So what does the kernel actually do? The kernel is the core layer that sits between your hardware and every program you run.
