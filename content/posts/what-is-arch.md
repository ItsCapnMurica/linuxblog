In great contrast to [Linux Mint](https://itscapnmurica.github.io/linuxblog/posts/what-is-mint/), Arch is commonly considered to be hard to learn, use, and install. But what even is it?

## What is Arch Linux?

Arch Linux (or "Arch") is a Linux distribution commonly considered to be a tougher one to use. That reputation is well earned in my opinion, as it is a tougher OS to use. It is extremely bare-bones, shipping with only a command line to assist you in installing it to your PC. Unlike [Mint](https://itscapnmurica.github.io/linuxblog/posts/what-is-mint/) which has some safeguards, but minuscule compared to Windows, Arch has very little, if any.

## How do I install Arch Linux?

There are 2 ways to install Arch, the easy way, and the hard (but cooler) way. But for both, you will need the [Arch ISO](https://archlinux.org/download/). Then [Flash the ISO to the USB](https://itscapnmurica.github.io/linuxblog/posts/how-to-flash/) and finally [Boot to the USB](https://itscapnmurica.github.io/linuxblog/posts/how-to-boot/).

### The Easy Way

The easy way is very simple to understand. Once booted into Arch, simply type "archinstall" and use mainly your arrow keys and enter to navigate the install. Simple as that, but very boring.

### The Hard (but cooler) way

I would not recommend this method to beginners, as it is difficult. I would prefer not to type all the many steps here, so I refer you to the [Arch Wiki](https://wiki.archlinux.org/title/Installation_guide). Follow that guide very carefully and you will have Arch installed!

## How do I use Arch Linux after installing it?

Congrats, the hard part is over. Now, the post-install experience! Arch is a very customizable distro, so if you wish, you can read/watch a guide on all the ways that you can customize the distro. To install apps, do not use apt like on Mint. Instead, for example, if I wanted to install Firefox, I would run "sudo pacman -S firefox". The only thing you would change between installing different apps is the package name, which in this case is firefox. Other than a few things I haven't mentioned, you are basically done!
