There are two ways to  boot an operating system, or OS. Those two ways are directly on your PC, or in a VM

## But what is a VM?

A VM, or virtual machine, is a way to boot an operating system without doing it on your actual PC. A VM can be used to test out operating systems, open suspicious files, or anything else you could imagine.

## What does a VM do?

A VM spoofs real hardware as much as it can while not actually being real hardware, however there are still ways to tell. Even if the OS can tell it is being run in a VM, most don't care. Most OSes you would ever try to run in a VM function no differently than if it was running on real hardware, so no worries about it not booting because of that.

## How do I use a VM?

There are many different ways to use a VM, but the one I personally recommend is VirtualBox, by Oracle. VirtualBox is an easy way to boot a VM in a user-friendly way while still being very customizable. You will first need to download an ISO, so search up "OS-NAME download", and choose the latest version ending in .iso. Then go through the VirtualBox GUI to choose the ISO you downloaded, choose its resources, and boot it. Then you have booted a VM for you to do anything in!
